# Easy Lesson — Website Source

A complete, fast, mobile-first, SEO-optimized website for **Easy Lesson**, a free **AI lesson solver**: snap a photo of any textbook page and get step-by-step exercise solutions, bullet notes, audio pronunciation and practice quizzes.

- **Stack:** clean static HTML/CSS/JS + a dependency-free Node build script (`build.js`). No framework, no database, no build step beyond `node build.js`.
- **Tool:** the AI lesson solver app is embedded on the homepage (`index.html`) in an iframe from `https://lesson-jet-gamma.vercel.app/` — the tool appears ONLY on the homepage; every other page links back to it.
- **Target audience:** worldwide/global. Site language: English. (The tool itself also reads textbook photos in English, Urdu and Sindhi — a multilingual feature, not country targeting.)

## Quick start

```bash
cd easy-lesson-website
node build.js          # regenerate blog pages, sitemap, RSS, homepage latest posts
```

Then deploy the whole folder (see `deployment-guide.md`). Re-run `node build.js` before every deploy after adding or editing posts.

To preview locally, serve the folder over HTTP (so `fetch("/ads-config.json")` works), e.g.:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## How to add a blog post daily (step by step)

1. Copy `blog-post-template.md` to `posts/<your-slug>.md` (slug = lowercase, words separated by hyphens, e.g. `how-to-revise-with-ai-notes.md`).
2. Fill in the frontmatter at the top:
   - `title` — the H1 shown on the post page.
   - `slug` — must match the filename (without `.md`).
   - `seo_title` — 50–60 characters (shown in Google results).
   - `meta_description` — 150–160 characters.
   - `focus_keyword` — the one keyword this post targets.
   - `date` — publish date `YYYY-MM-DD`; `updated` — same as date for a new post.
   - `author` — keep `Easy Lesson Team`.
   - `categories` — pick from the existing set: `AI Study Tools`, `Homework Help`, `How-To Guides`, `Study Tips`, `For Teachers` (or add a new one — it will appear as a filter button automatically).
   - `tags` — 3–4 lowercase hyphenated tags.
   - `featured_image` — keep `/assets/images/blog/default.svg` or point at your own image under `assets/images/blog/`.
   - `featured_image_alt` — describe the image in words.
   - `status` — `draft` until you have reviewed the post, then `published` (see note below).
3. Write the body in Markdown: intro, `##` sections, `###` subsections, an FAQ section (questions as `###` headings), and a conclusion ending with a CTA link to the tool: `[Try the free AI lesson solver](/#tool)`.
4. Aim for 800–1200 words. Use the focus keyword naturally (first 100 words, one `##` heading, a few times in the body). No keyword stuffing, no fake statistics, no copied text.
5. Run `node build.js` and check the new page at `blog/<your-slug>.html`, the listing at `blog/`, `sitemap.xml` and `rss.xml`.
6. Deploy the whole folder.

> Note: `build.js` includes every `.md` file in `posts/` in the listing, sitemap and RSS — including `status: draft` starter posts — so the site looks complete from day one. Before applying for AdSense, review/edit each starter post, set its `status` to `published`, rebuild and redeploy (see `adsense-guide.md`).

## How to edit keywords and meta data

Everything lives in **`seo-config.json`**:

| Field | What it does |
|---|---|
| `primary_keyword` | `"AI lesson solver"` — used by the homepage H1 and docs. |
| `secondary_keywords` | The 10 supporting keywords the starter posts target. |
| `long_tail_keywords` | 30 long-tail keywords (see also `keyword-plan.md`). |
| `pages` | Per-page `title` + `description` for the static pages. The homepage and generated blog pages use their own head blocks / post frontmatter instead. |
| `verification` | Placeholders for Google Search Console, Bing, GA4 and GTM codes — see "Replace placeholders" below. |

To change a blog post's SEO title/description, edit that post's `seo_title` / `meta_description` in its frontmatter, then rebuild.

## How to replace placeholders

| Placeholder | Where it appears | Replace with |
|---|---|---|
| `https://www.easylesson.example` | Canonical/OG URLs in every `.html`, `seo-config.json` (`base_url`), `robots.txt`, `sitemap.xml` (regenerated) | Your real domain (with `https://`, no trailing slash). Then rebuild + redeploy. |
| `[CONTACT_EMAIL]` | Contact page, Privacy/Terms/Disclaimer/Cookie pages, `seo-config.json` | Your real public contact email. |
| `ca-pub-XXXXXXXXXXXXXXXX` | `<!-- ADSENSE_SCRIPT: … -->` comment in every page `<head>`, `ads-config.json` (`publisher_id`), `ads.txt` | Your real AdSense publisher ID **after approval** (see `adsense-guide.md`). |
| `REPLACE_WITH_AD_SLOT_ID` | `ads-config.json` (7 slots) | Real AdSense ad-unit slot IDs after approval. |
| `REPLACE_WITH_GSC_VERIFICATION_CODE` etc. | `seo-config.json` → `verification` | Real codes from Search Console / Bing / GA4 / GTM, then paste the corresponding meta tag / script where the HTML comments indicate (each page `<head>`). |
| Social `#` links | Footer of every page | Your real profile URLs. |
| `data-endpoint="#"` | Contact form in `contact.html` | Your Formspree endpoint or Netlify Forms setup — see below. |
| Favicon / logo | `favicon.svg`, header `.logo-mark` | Replace with your brand mark if you have one. |
| `og-image.png` | `assets/images/og-image.png` (+ `.svg` source) | Replace with a branded 1200×630 image if you prefer. |

### Contact form setup (pick one)

- **Formspree (easiest):** create a free form at formspree.io, copy its endpoint (`https://formspree.io/f/xxxxxx`), and put it in `contact.html` as `data-endpoint="https://formspree.io/f/xxxxxx"`. The JS in `main.js` will POST to it and show the success message.
- **Netlify Forms:** deploy on Netlify, add `netlify` + `name="contact"` attributes to the `<form>`, and remove the `data-endpoint` attribute (Netlify intercepts the POST). Remove the JS fetch branch is not required — the form will still work because Netlify handles the submit; keep the success note in the README for reference.
- Until an endpoint is set, the form shows a success message but does **not** deliver anything (the form note on the page says so).

### AdSense setup (summary — full steps in `adsense-guide.md`)

1. Publish 15–20 quality posts first (review the 10 starter drafts, then publish from `content-calendar.md`).
2. Apply in AdSense with your real domain; paste the verification code where the `ADSENSE_SCRIPT` comments point.
3. After approval: put your real publisher ID in `ads-config.json` + `ads.txt` + the `ADSENSE_SCRIPT` comments, put real slot IDs in `ads-config.json`, set `"ads_enabled": true`, rebuild, redeploy.
4. **Never click your own ads, never buy fake traffic.** That gets the account banned.

## SEO notes

- One H1 per page; semantic HTML5; canonical tags; OG/Twitter cards; JSON-LD (`WebSite`, `Organization`, `WebApplication`, `FAQPage`, `BreadcrumbList`, `BlogPosting`).
- `sitemap.xml` + `rss.xml` regenerate on every `node build.js` run.
- The tool iframe uses `loading="lazy"`, a reserved `min-height` (no layout shift), `allow="camera; microphone"`, and a "Open the tool in a new tab" fallback. It has **no** `sandbox` attribute — the tool needs camera/uploads/storage to work.
- Keep publishing: the `content-calendar.md` has one post per day for 30 days.
