Algebra for beginners starts with one idea: algebra is really just arithmetic with one twist — sometimes a number is unknown, and we use a letter to stand in for it. Once you see a variable as a "mystery number" waiting to be found, algebra becomes a puzzle you can solve rather than a code you must memorise.

## Algebra for Beginners: A Variable Is a Mystery Number

A variable is a letter, usually x, that stands for a number we do not know yet. When we write x + 7 = 15, we are saying: "Some number, plus 7, equals 15." The variable x is the mystery number. Your job is to find which number fits.

Think of a covered box. Inside the box is a number of counters. If someone tells you that the box plus 7 more counters makes 15, you can work out that the box holds 8 counters, because 8 + 7 = 15. The letter x is just the label on the box. It is not magic; it is a placeholder.

Variables can also stand for numbers that change. In the expression 2x, the value depends on x: if x is 3, then 2x is 6; if x is 10, then 2x is 20. This is why algebra is powerful. One expression can describe a whole pattern, like "double any number", instead of a single calculation.

## Expressions, Terms, and Coefficients

An expression is a maths phrase that combines numbers, variables, and operations. The expression 3x + 5 has two terms: 3x and 5. A term is a chunk separated by a plus or minus sign. The number 3 in front of x is called the coefficient — it tells you how many x's you have. So 3x means 3 times x, or x + x + x.

The term without a variable, like the 5 in 3x + 5, is called the constant. It stays the same whatever x is. Knowing these words matters because teachers and textbooks use them constantly, and the words are far less scary than they sound: coefficient = the number in front of the letter, constant = the plain number on its own.

Like terms can be combined. In 2x + 5x, both terms contain x, so they combine to 7x. In 2x + 3, the terms are different kinds (one has x, one does not), so they cannot be combined into a single term. A common beginner error is writing 2x + 3 = 5x. It is not: the 3 has no x attached, so it stays separate.

## Worked Example: Solving x + 7 = 15

To solve an equation, undo what has been done to x. In x + 7 = 15, the number 7 has been added to x. Undo addition with subtraction: subtract 7 from both sides. On the left, x + 7 − 7 leaves just x. On the right, 15 − 7 = 8. So x = 8.

The golden rule of equations is: whatever you do to one side, do to the other side. An equation is like a balanced scale. If you remove 7 from one pan, you must remove 7 from the other pan to stay balanced. This "do the same to both sides" rule is the single most important idea in algebra.

Always check your answer by putting it back into the original equation. If x = 8, then x + 7 = 8 + 7 = 15. That matches the right-hand side, so the answer is correct. Checking takes seconds and catches most careless errors.

## Worked Example: Solving 3x = 24

In 3x = 24, the variable x has been multiplied by 3. Undo multiplication with division: divide both sides by 3. On the left, 3x divided by 3 leaves x. On the right, 24 divided by 3 is 8. So x = 8.

Check: 3 times 8 is 24, which matches. Notice that this example gives the same answer as the last one by coincidence — the two equations are different, and the checking step is what proves each one.

A useful way to think about 3x = 24 is "3 groups of x make 24, so one group is 24 divided by 3". The division picture works well for multiplication equations. For addition equations, the "undo" picture works well. Both are the same rule: do the opposite operation to both sides.

## Worked Example: Solving 2x + 5 = 17

Two-step equations need two undo steps, in reverse order. In 2x + 5 = 17, x has been multiplied by 2 and then 5 has been added. Undo in reverse: first subtract 5 from both sides, giving 2x = 12. Then divide both sides by 2, giving x = 6.

Check: 2 times 6 is 12, plus 5 is 17. Correct. The reverse-order idea matters: if you divided by 2 first, you would get x + 2.5 = 8.5, which is messier (though still solvable). Peeling off the operations in reverse order keeps the numbers whole and the working clean.

![Solving a two-step equation](/assets/images/blog/algebra-for-beginners-variables-diagram-1.svg)

A neat mental image is unwrapping a parcel. The last layer put on is the first layer you take off. In 2x + 5, the +5 was the last thing done, so it is the first thing undone. This image helps whenever an equation has two or more steps.

## Common Mistakes to Avoid in Algebra

The most common mistake is doing something to only one side of the equation. If you subtract 7 from the left, you must subtract 7 from the right. An unbalanced equation gives a wrong answer that usually fails the check — which is exactly why checking matters.

Another mistake is combining unlike terms, as in 2x + 3 = 5x. Remember: only terms with the same variable part combine. The expression 2x + 3 is already as simple as it gets.

A third mistake is misreading 3x as "3 plus x" or "3 and x". The expression 3x always means 3 times x. When a number sits directly next to a letter with nothing between them, multiplication is implied. This convention appears in every algebra problem, so it is worth learning early.

## Try It Yourself: Practice with Answers

Try these three problems, then check your answers below.

1. Solve x − 4 = 11.
2. Solve 5x = 45.
3. Solve x/3 = 7.

Answers: (1) Add 4 to both sides: x = 15. Check: 15 − 4 = 11. (2) Divide both sides by 5: x = 9. Check: 5 times 9 = 45. (3) Multiply both sides by 3: x = 21. Check: 21 divided by 3 = 7. If you solved all three and checked each one, you have the core skill. If one felt tricky, ask which operation was done to x and undo it on both sides.

## Conclusion

A variable is a mystery number, and an equation is a balanced scale. To solve it, undo the operations on the variable — doing the same thing to both sides — and then check by substituting your answer back in. Start with one-step equations, then peel two-step equations in reverse order. Keep practising the undo habit, and algebra will feel less like a code and more like a puzzle you already know how to solve.

## FAQ

### What is a variable in algebra?

A variable is a letter, usually x, that stands for a number we do not know yet or a number that can change. In x + 7 = 15, x is the mystery number that makes the equation true. In the expression 2x, x can be any number, and 2x means double that number.

### What does 3x mean?

3x means 3 times x. When a number sits directly next to a letter with no symbol between them, multiplication is implied. So if x = 4, then 3x = 12. It never means 3 plus x.

### How do you solve a one-step equation?

Undo the operation on x by doing the opposite operation to both sides. If 7 was added, subtract 7 from both sides. If x was multiplied by 3, divide both sides by 3. Then check by putting your answer back into the original equation.

### What is the golden rule of solving equations?

Whatever you do to one side, do to the other side. An equation is like a balanced scale: changing only one side breaks the balance and gives a wrong answer. Every step of solving must keep both sides equal.

### Can you add 2x and 3 to get 5x?

No. Only like terms combine. The term 2x has a variable part, while 3 is a constant with no variable part, so they cannot merge. The expression 2x + 3 is already in its simplest form.
